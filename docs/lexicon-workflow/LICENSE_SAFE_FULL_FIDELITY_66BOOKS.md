# 성경 66권 원어 한글사전 · License-Safe Full-Fidelity SSOT

Status: ACTIVE · sole semantic-quality policy SSOT

모든 책은 Rights-PASS source와 동일한 Full-Fidelity 검증 기준을 사용한다. 의미 권위는 원문/lemma identity → 직접 문맥·형태론·용례 → Rights-PASS pinned 원어사전 → Rights-PASS 공개 신학·어휘 자료 → GPT·자비스·Claude·Gemini 독립 분석 순서다. AI 다수결은 Evidence보다 우선하지 않는다.

모든 R0–R4 Strong은 rights-license, source-identity, source-full-fidelity, sense-structure, qualifier-completeness, morphology-boundary, corpus-alignment, korean-naturalness, theological-overreach, provenance-complete, fixed-four-independent, fingerprint-same-baseline, deterministic-comparison, unresolved-zero, regression을 AND로 통과해야 한다.

모든 Strong은 source의 실제 sense/subsense, parent/depth/order, qualifier, usage restriction, homograph/extended Strong identity, morphology, provenance를 손실 없이 한국어에 매핑한다. H776은 정보 보존 방식의 Golden Reference이지 node 수 템플릿이 아니다.

각 Strong Evidence는 sourceUnitCount와 koMappedUnitCount가 같고 missingSourceInformation, improperlyMergedSourceInformation, extraUnsupportedKoInformation, structureMismatch, qualifierMismatch, identityBoundaryMismatch, morphologyBoundaryMismatch, provenanceMissing, corpusAlignmentMismatch, theologicalOverreach, unresolved가 모두 0일 때만 PASS할 수 있다.

의미 생성·감사·쟁점 판정은 GPT·자비스·Claude·Gemini 네 역할만 사용한다. 제5 LLM, 로컬 모델, 임시 tie-breaker는 금지한다. 네 역할은 동일 pinned Evidence baseline에서 독립 제출하고 네 결과 모두가 있어야 GPT public-evidence final adjudication으로 간다.

R3는 Rights-PASS 공개 신학·어휘 Evidence를 추가하고, R4는 extended public lexical/scholarly/biblical-usage research를 추가한다. R4도 Evidence가 해결되면 GPT가 semantic PASS를 판정하며, 해결되지 않으면 HOLD/DISPUTE다. 사용자는 Strong별 최종 문구를 고르지 않는다.

자동 흐름: C0 PASS → pinned source capture → deterministic source units → Korean candidate → Full-Fidelity verifier → book context/morphology/corpus verifier → Fixed Four independent evidence → deterministic comparison → GPT public-evidence adjudication → PASS|HOLD|DISPUTE.

폐기 규칙: Evidence-First만으로 완료 판정, 3-of-3 consensus 자체를 의미 권위로 사용, Tier가 낮다는 이유로 일부 AI만 사용, R4 human final wording, Rights-PASS 없는 웹자료 ingest, H776 node 수 복제, App/Live/Approved를 source-quality complete와 동일시. 구 정책 파일·구 Tier matrix·구 consensus verifier는 active tree에서 제거하고 anti-regression verifier가 재등장을 차단한다.
