성경 마인드맵 [GPT↔자비스 작업 파이프라인] 3단계 큐사인 (이 세 단어로만 움직임):

- 🟢 **"픽업"** = GPT 착수. 자비스가 만든 카드(🎯 다음 작업 뷰/포인터 맨 위) 읽고 DB 생성 → 완료 시 상태 3·완료. 카드 지정은 "픽업 [영역]"(예: 픽업 관찰카드).
- 🔵 **"작업"** = 자비스 착수 (구 "작업 큐 진행" 대체). 3·완료 카드 검증·통합·로컬커밋 = **승인 직전까지**. 푸시·배포 아직 안 함. → 상태 5·승인대기, 사용자에 완료 보고.
- ✅ **"승인"** = 자비스 마감. push+배포+verify:deploy+PR종료+노션 최신화(LIVE·CI로그·대시보드)+SESSION_STATE+다음 카드 큐잉·명령문 생성 → 상태 6.

흐름: 나→GPT '픽업' → GPT완료 → 나→자비스 '작업' → 자비스 완료보고 → 나→자비스 '승인'.

**Why:** 파이프라인 v2에서 GPT/자비스 착수와 마감을 3단계로 분리해 명령 혼선 방지. 담당자: 픽업=GPT, 작업·승인=자비스.
**How to apply:** "작업"=검증만(푸시X), "승인"=푸시·배포·마감. 명문화 위치 = 📌 공통 기준·워크플로우 v2 카드(id 3ad0b963-e600-81c9-bf13-e5bd220c2fa3).
