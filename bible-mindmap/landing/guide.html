01 · START

빠른 시작

랜딩페이지에서 성경 마인드맵 시작하기를 누르면 `/app/`으로 이동합니다. 앱 안에서는 자료 추가 패널을 열어 구절·인물·장소·시대 노드를 캔버스에 배치합니다.

1

자료 추가 열기

캔버스의 자료 추가 버튼을 눌러 추가할 자료 종류를 선택합니다.

2

본문 또는 항목 검색

성경 권·장·절, 인물명, 장소명 또는 시대를 검색해 결과를 선택합니다.

3

노드 배치와 연결

노드를 드래그해 배치하고 관련 노드 사이에 관계를 연결합니다.

4

연구 내용 저장

본문 수정·주석·메모와 캔버스 상태를 저장해 다음 연구에서 이어갑니다.

02 · CANVAS

캔버스와 노드

캔버스는 성경 연구의 중심 공간입니다. 구절·인물·장소·시대를 개별 창으로 열고, 같은 연구 맥락 안에서 관계를 시각화합니다.

📖 구절 노드

본문, 역본 전환, 원어, 교차 참조, 주석과 관련 연구 도구를 담습니다.

본문 연구 중심

👤 인물 노드

이름 변화, 원어 의미, 가족·동료 관계, 동시대 인물과 관련 본문을 확인합니다.

관계 탐색

📍 장소 노드

성경 지명, 위치, 시대, 관련 인물과 동명이칭 장소를 문맥에 따라 구분합니다.

지리·문맥

🕰️ 시대 노드

족장·출애굽·왕정·포로·제2성전·사도 시대를 인물과 사건에 연결합니다.

역사 흐름
03 · TEXT & ORIGINAL

본문·원어·구문 연구

구절 노드 안에서 개역한글·WEB·원어를 전환하고, 히브리어·헬라어 형태와 Strong 번호, 병렬 본문과 구문 구조를 살펴봅니다.

도구용도핵심 동작

원어 검색히브리어·헬라어·Gloss·KRV 검색형태소 필터와 책별 분포 확인

04 · CONTEXT BIBLE

문맥 성경과 Arc

문맥 성경은 한 권 전체를 장별 의제와 담화 구조로 펼쳐 보여줍니다. Arc는 장·단락·주제 사이의 연결 근거를 시각적으로 설명합니다.

책 전체 거시구조

창세기·로마서처럼 책의 큰 단락과 전환점을 한 화면에서 확인합니다.

장별 핵심 의제

각 장의 중심 사건과 신학 주제를 비교해 전체 흐름 속 위치를 파악합니다.

담화 마커

히브리어·헬라어 담화 표지와 논증 접속사를 통해 흐름 전환을 확인합니다.

Arc 근거

연결선이 만들어진 본문·문맥·신학적 이유를 툴팁과 설명으로 확인합니다.

05 · CANONICAL TRACE

정경 추적 72개 개념

씨·언약·성전·피·안식·영광 등 72개 개념을 513개 큐레이션 용례로 추적합니다. 한글·히브리어·헬라어·Strong·주제 문구로 검색할 수 있습니다.

1

개념 검색

정경 추적 화면에서 개념명, 원어, Strong 번호 또는 설명 문구를 입력합니다.

2

개념 상세 열기

개념의 정의, 원어, 개혁주의 해석 앵커와 정경 단계 요약을 확인합니다.

3

정경 전체 용례 확인

첫 용례부터 마지막 용례까지 구약과 신약의 발전 흐름을 읽습니다.

중요: 공개 앱의 정경 검색은 서버나 사용자용 NVIDIA 호출 없이 브라우저에서 동작합니다.
06 · CROSS REFERENCE

교차 참조 연결

교차 참조는 선택한 구절과 관련된 핵심·추가 본문을 캔버스에 연결합니다. 모바일에서는 본문 수정 흐름을 방해하지 않도록 사용자가 버튼을 눌렀을 때만 하단 시트가 열립니다.

핵심 참조

현재 본문과 직접적으로 연결되는 우선 참조를 먼저 확인합니다.

추가 참조

필요할 때 펼쳐 더 넓은 본문 관계를 선택합니다.

선택 일괄 추가

행 전체를 눌러 선택한 뒤 한 번에 노드를 추가하고 자동 연결합니다.

본문 화면 유지

모바일 하단 시트 높이를 제한해 원래 연구 화면의 맥락을 유지합니다.

07 · NOTES & STORAGE

주석·메모·저장

본문을 직접 수정하고, 선택한 범위에 주석·하이라이트를 남기며, 설교 구성과 개인 연구 기록을 저장할 수 있습니다.

본문 직접 수정

연구 목적에 맞게 구절 노드의 표시 내용을 편집합니다.

개인 주석

본문 범위를 선택해 핀·주석·하이라이트를 남깁니다.

설교 연구

서론·본론·결론 또는 이야기 구조로 설교 아이디어를 작성합니다.

개인 저장

브라우저 중심으로 캔버스와 연구 내용을 보관하고 다시 불러옵니다.

08 · MOBILE

모바일 사용법

모바일에서는 작은 화면에서 본문을 계속 보면서 필요한 도구만 하단 시트로 여는 방식으로 최적화되어 있습니다.

1

구절 선택

구절을 눌러도 교차 참조가 자동으로 열리지 않으므로 본문 수정과 연구를 계속할 수 있습니다.

2

필요한 도구만 열기

`교차 참조 n`과 같은 런처를 눌렀을 때만 하단 시트가 열립니다.

3

행 전체로 선택

작은 버튼 대신 항목 전체를 눌러 참조 구절을 선택·해제합니다.

4

배경 또는 닫기로 복귀

시트를 닫으면 원래 선택한 구절과 캔버스 위치로 돌아갑니다.

09 · QUALITY & SAFETY

데이터와 AI 운영 기준

NVIDIA Build API는 사용자에게 실시간 AI 답변을 제공하는 서버 기능이 아니라, 개발 단계에서 검색·데이터 품질을 평가하고 개선하는 기술 도구로 사용합니다.

사용자 runtime 호출 없음

공개 앱에는 NVIDIA API 키나 브라우저 직접 호출을 넣지 않습니다.

정적 공개 검색

검증된 데이터 필드를 브라우저에서 점수화해 무료 공개 구조를 유지합니다.

Verifier와 CI

정경 데이터, 원어 참조, 검색 계약과 모바일 회귀를 자동 검사합니다.
