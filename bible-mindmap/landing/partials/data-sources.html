DATA SOURCES & ATTRIBUTION

데이터 출처와 이용 기준

성경 마인드맵은 공개 성경 연구 자료와 프로젝트에서 직접 검토한 큐레이션 데이터를 함께 사용합니다. 외부 자료의 저작권과 라이선스는 각 제공처의 조건을 따르며, 출처를 숨기거나 프로젝트 자체 데이터로 오인되게 표시하지 않습니다.

אΩ

원문·형태론·Strong 연결

  • STEPBible Data
    TAGNT 헬라어 신약·TAHOT 히브리어 구약의 lemma, 형태론, 음역, Strong 연결과 영어 gloss. CC BY 4.0.
  • OpenScriptures Strong’s Dictionaries
    헬라어·히브리어 Strong 사전 정의. 저장소 고지에 따른 Public Domain 자료.
  • BibleHub
    Strong 번호별 원어 사전을 확인하기 위한 외부 참조 링크. BibleHub 콘텐츠를 운영 DB에 복제한다는 의미가 아닙니다.
📖

성경 본문·번역·사전

  • Bolls.life API
    앱에서 사용하는 개역한글·영문 역본과 BDB 히브리어 사전 조회 경로. 실제 제공 범위와 이용 조건은 Bolls.life의 현행 정책을 따릅니다.
  • 본문 표준화
    책·장·절 참조는 저장소의 OSIS 기반 표준 ID로 정규화하며, 역본별 본문과 프로젝트의 해설·관계 데이터는 서로 구분합니다.
🔗

교차 참조·성경 지리

  • OpenBible.info Cross References
    성경 구절 사이의 교차 참조 후보와 참조 강도 자료.
  • OpenBible.info Bible Geocoding Data
    성경 지명, OSIS 등장 구절, 고대·현대 위치 후보 및 좌표. 재현 가능한 고정 커밋을 사용하며 CC BY 4.0.
  • Wikidata
    인물·장소 식별 보조와 Q 식별자 참조. 성경 본문과 프로젝트 검증 자료를 우선하고 외부 식별자는 보조 근거로 사용합니다.
🧭

프로젝트 큐레이션 데이터

  • 정경 추적·문맥 성경·Arc
    개념 정의, 정경 단계, 용례, 관계 근거와 신학 해설은 성경 마인드맵 프로젝트에서 직접 작성·검토한 큐레이션 자료입니다.
  • 인물·장소·시대 관계
    성경 본문을 1차 근거로 사용하며, 역사적 추정이나 논쟁적 항목은 확정 사실과 구분합니다.
  • AI·NVIDIA 사용 경계
    AI 결과는 내부 후보 생성과 품질 평가에만 사용하며, schema 검증·성경 검증·신학 검토·사람 승인을 거치기 전에는 공개 사실 데이터로 확정하지 않습니다.
저작권·라이선스 안내

각 외부 데이터셋과 성경 역본은 해당 제공처의 저작권·라이선스·이용 약관을 따릅니다. 성경 마인드맵의 프로그램 코드, UI, 프로젝트 자체 큐레이션 자료에 대한 권리와 외부 원자료의 권리는 별개입니다. 출처 또는 라이선스 표기에 오류가 발견되면 biblemindmap9@gmail.com으로 알려주세요.
