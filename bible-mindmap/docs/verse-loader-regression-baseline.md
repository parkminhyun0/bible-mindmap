# 구절 로더 회귀 기준선

## 문제 정의

이 문제는 신규 번역 엔진 구축 문제가 아니라, 리뉴얼·업그레이드 과정에서 기존에 정상 작동하던 구약·신약 전체 장절 로더의 정확도와 전환 성능이 저하된 회귀 문제다.

기준선은 다음과 같다.

- 창세기부터 요한계시록까지 모든 책·장·절이 정상 표시된다.
- 개역한글, WEB, 원어 탭이 동일 참조 범위를 완전하게 제공한다.
- 구약과 신약 사이를 반복 전환해도 빈 화면, 부분 응답, 잘못된 장절 매핑, 무한 로딩이 발생하지 않는다.
- 최초 로딩 이후 장 단위 캐시가 작동해 재전환이 빠르다.
- 리뉴얼 UI와 AI 기능은 유지하되 기존 로더의 성능·정확도를 훼손하지 않는다.

## 현재 복구 내용

PR #79에서 다음 회귀를 복구했다.

- 불필요한 `cache: no-store` 제거
- 장 단위 Promise/LRU 캐시 및 병렬 프리로드 복원
- 부분 응답을 성공으로 처리하지 않도록 범위 완전성 검사 추가
- WEB 로마서 14:24-26을 앱 참조 로마서 16:25-27로 정규화
- TAGNT 누락 절을 NTGT 보조 공급원으로 보완

## 필수 회귀 검증 표본

### 구약

- 창세기 1장
- 창세기 50장
- 시편 119편
- 말라기 3장
- 말라기 4장

### 신약

- 마태복음 1장
- 사도행전 28장
- 로마서 14장
- 로마서 16장 23-27절
- 요한계시록 22장

## 전환 시나리오

1. 개역한글 → WEB → 원어를 빠르게 반복 전환한다.
2. 구약 장 → 신약 장 → 구약 장을 반복 전환한다.
3. 같은 장을 닫았다 다시 열어 캐시 재사용 여부를 확인한다.
4. 일부 공급원 응답이 부족할 때 빈 절을 표시하지 않고 보조 공급원 병합 또는 명시적 오류로 처리하는지 확인한다.
5. 로마서 16:25-27에서 개역한글·WEB·헬라어가 모두 표시되는지 확인한다.

## 완료 조건

- 위 표본과 전환 시나리오가 데스크톱과 모바일에서 모두 통과한다.
- production build와 기존 P0/P1 검증이 통과한다.
- 라이브 GitHub Pages에서 최신 `main` 배포가 확인된다.
- 특정 구절만이 아니라 전체 장절 로더 회귀를 막는 자동 검증이 CI에 연결된다.
