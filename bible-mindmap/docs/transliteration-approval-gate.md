# 원어 한글 음역 자모 대응표 · 박 목사님 확인 게이트

## 상태

- 정책 상태: `pending-pastor-approval`
- 승인 전 데이터 변경 금지
- 이번 PR은 제안표·검증기·CI 게이트만 추가한다.
- `labelHe`·`labelGr`와 산문 해설의 실제 음역 값은 수정하지 않는다.

## 표시 원칙 제안

1. 관용 표기가 있는 경우: `원어 (SBL 엄밀 음역 / 개역개정 관용 표기)`
2. 관용 표기가 없는 경우: `원어 (SBL 엄밀 음역)`
3. 원어 철자·모음부호·악센트·Strong·lemma·형태론은 보존한다.
4. 엄밀식과 관용식이 같으면 중복 병기하지 않는다.
5. 문맥 의존 음가는 자동 일괄 변환하지 않는다.

## 확인이 필요한 자모·조합 초안

| 구분 | 원문/SBL 기호 | 제안 처리 | 확인 항목 |
|---|---|---|---|
| 히브리어 shin/sin | `שׁ / שׂ`, `š / ś` | 시·쉬 / 스·사 계열을 단어 단위로 검토 | 자음 뒤 모음과 기존 관용 표기의 우선순위 |
| 히브리어 후음 | `ח / ה / ע`, `ḥ / h / ʿ` | 흐·ㅎ·아인 표지 후보를 단어별 검토 | `ע`를 표기할 범위와 생략 조건 |
| furtive patach | 어말 후음 앞 `a` | 실제 발음 순서를 보존하는 후보 | `מָשִׁיחַ → 마시아흐` 승인 여부 |
| 헬라어 ευ | `eu` | 후속 자음에 따른 에우·에브·에프 계열을 문맥 검토 | 학술식과 한국 교회 관용식 병기 기준 |
| 헬라어 σσ·υ·ῥ | `ss / y / rh` | 단어별 엄밀식과 관용식 대조 | 위·유, 흐·르 등 한국어 근사 규칙 |

## 대표 표시 예시

- `מָשִׁיחַ (마시아흐 / 메시아)` — **승인 전 예시이며 아직 데이터에 적용하지 않음**
- `Χριστός (크리스토스 / 그리스도)` — **승인 전 예시이며 아직 데이터에 적용하지 않음**
